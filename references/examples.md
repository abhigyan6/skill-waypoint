# Worked routing examples

Skill names here are fictional capabilities, not dependencies or a registry. Resolve actual candidates from the current host catalog.

## Fix a dashboard keyboard trap

Request: “Fix keyboard focus getting trapped in this dashboard modal.”

Available: a dashboard design guide, an accessibility specialist, a general redesign workflow, and an explicit-only engineering framework.

Choose the accessibility specialist because the defect concerns keyboard behavior. Inspect the existing modal and reproduce the focus failure, make the targeted change, then verify opening, keyboard navigation, closing, and focus restoration. Existing project checks still apply. Neither a redesign nor an optional engineering framework follows from this request.

## Turn research into a document

Request: “Compare these vendors and prepare a formatted decision memo.”

Use available research guidance for gathering current evidence, then a document specialist when creating the memo. Preserve source links and distinguish facts from judgments. Do not load every writing and design skill at the start. Sending the memo is a separate action governed by the user's authorization.

## Explicit-only preference

Request: “Pick whatever skills fit this feature.”

A relevant framework is marked explicit-only. Broad routing permission does not name or enable it. Use eligible specialists or ordinary capabilities. If the user later explicitly requests that framework, read and apply it within its scope and the host's instruction hierarchy.

## Missing optional metadata

A host catalog exposes a suitable skill and its documented default permits automatic selection. The skill lacks a policy file. Apply the host default; do not block selection merely because the optional file is missing. A contrary project rule or explicit-only manifest field still restricts automatic use.

## Active plugin cache

The host lists version 2 of a document plugin as active. Versions 1 and 2 both exist in a local cache. Use the host's version 2 entry. Do not ignore the active skill because its path contains “cache,” and do not choose version 1 because a filesystem search found it first.

## No specialist fits

Request: “Fix this sentence's spelling.”

Make the correction directly. There is no obligation to load a writing workflow, create a plan, or find a new skill.
